# Revisión visual de idiomas

Esta lista se usa antes de publicar una nueva versión. Las traducciones pueden corregirse sin tocar el funcionamiento del programa.

## Idiomas representativos

- [ ] Español: texto completo y controles alineados.
- [ ] English: texto completo y controles alineados.
- [ ] Français: botones largos sin cortes.
- [ ] Deutsch: botones largos sin cortes.
- [ ] Italiano: terminología natural.
- [ ] Português: terminología natural.
- [ ] Català: «Actualitzar llista» y «Desar com a...».
- [ ] العربية: escritura de derecha a izquierda, conservando la cabecera y las columnas en su sitio.
- [ ] 简体中文: caracteres visibles y selector completo.
- [ ] 日本語: caracteres visibles y selector completo.
- [ ] हिन्दी: caracteres visibles y selector completo.

## Comprobaciones comunes

- [ ] Cambiar de idioma no necesita reiniciar.
- [ ] El nombre del idioma se ve completo en el selector.
- [ ] Los botones se ajustan y no pisan el texto inferior.
- [ ] La ventana principal, el editor, las preferencias y la ayuda son legibles al 100 %, 125 % y 150 %.
- [ ] Ejecutar `Tools\ValidateLanguagePacks.ps1` sin errores estructurales.
- [ ] Preferencias, Historial, editor, avisos y errores permanecen en el idioma seleccionado.
- [ ] Ningún paquete omite textos ni altera `{fecha}`, `{hora}`, `{contador}`, `{ventana}` o los marcadores numéricos.
