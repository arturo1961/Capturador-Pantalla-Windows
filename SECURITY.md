# Seguridad y privacidad

CapturaLibre trabaja con capturas potencialmente privadas. No publica ni transfiere imágenes a internet. La ocultación se hace con píxeles negros sólidos sobre el archivo final, no con un efecto de desenfoque reversible.

**Aviso:** hasta que se pruebe la beta en Windows no hay ninguna garantía de protección ante capturas accidentales, escritorios protegidos o aplicaciones que bloqueen la captura. Revisa toda imagen antes de enviarla.

Si detectas un problema de seguridad, evita publicarlo junto con una captura que contenga credenciales o datos personales. Contacta con el mantenedor del repositorio por un canal privado cuando éste lo habilite.
