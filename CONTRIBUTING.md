# Cómo contribuir

Gracias por querer ayudar a CapturaLibre. El proyecto busca ser sencillo, gratuito, accesible y respetuoso con la privacidad.

- Usa **C# / .NET 8** y Windows Forms; evita añadir dependencias salvo necesidad clara.
- No añadas telemetría, publicidad, red o subidas automáticas de capturas.
- Mantén la interfaz en español o proporciona traducciones completas.
- Documenta los cambios con una descripción, capturas sin datos privados y pasos para reproducir los fallos.
- Ejecuta `dotnet build CapturaLibre/CapturaLibre.csproj -c Release` en Windows y comprueba la [lista de pruebas](PRUEBAS.md).
- No incluyas secretos, cuentas de donaciones ni ejecutables binarios compilados sin una razón clara.

Al enviar una contribución aceptas que se distribuya bajo la licencia MIT.
